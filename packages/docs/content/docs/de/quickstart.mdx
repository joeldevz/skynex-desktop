# Schnellstart

## Schnellster Weg

Die CLI-Schritte benötigen ein Skynex-Release mit CLI-Dateien. Die veröffentlichte Version 0.1.1 enthält weder CLI-Dateien noch das neue Linkschema. Diese Checkout-Änderungen sind unveröffentlicht. Prüfe zuerst [Installieren](/de/install/).

1. Installiere [OpenCode](https://opencode.ai).
2. Installiere das Skynex-App-CLI gemäß [Installieren](/de/install/).
3. Führe `skynex-app --ui-password be-creative-here` aus.
4. Öffne die URL, die das CLI ausgibt (normalerweise `http://localhost:3000`).
5. Um es auf deinem Handy zu nutzen, starte einen [Tunnel](/tunnels/) und scanne den QR-Code.

Du solltest die Skynex-Sessionliste im Browser sehen. Der separate Befehl `skynex` verwaltet Agent-Werkzeuge.

Verwende ein starkes UI-Passwort, besonders wenn du die Instanz ins Internet öffnen willst.

Wenn die Seite nicht lädt, sieh unter [Troubleshooting](/troubleshooting/) nach.

## Welche App soll ich verwenden?

- verwende **Desktop** für die tägliche Arbeit auf macOS, Windows oder Linux
- verwende **Web** für den Remote-Zugriff und zum Prüfen vom Handy aus
- die **VS Code**-Einträge gehören zu Upstream-OpenChamber und verteilen Skynex nicht
