# Snel aan de slag

## De snelste manier

De CLI-stappen vereisen een Skynex-release met CLI-bestanden. De gepubliceerde versie 0.1.1 bevat geen CLI-bestanden of nieuw linkschema. Deze wijzigingen zijn niet gepubliceerd. Lees eerst [Installeren](/nl/install/).

1. Installeer [OpenCode](https://opencode.ai).
2. Installeer de Skynex-app-CLI volgens [Installeren](/nl/install/).
3. Voer `skynex-app --ui-password be-creative-here` uit.
4. Open de URL die de CLI toont, meestal `http://localhost:3000`.
5. Wilt u uw telefoon gebruiken? Start dan een [tunnel](/nl/tunnels/) en scan de QR-code.

U ziet de Skynex-sessielijst in uw browser. De aparte opdracht `skynex` beheert agenttools.

Gebruik een sterk wachtwoord voor de interface, zeker als u de instantie via internet bereikbaar wilt maken.

Laadt de pagina niet? Kijk dan bij [Problemen oplossen](/nl/troubleshooting/).

## Welke app past bij mijn werk?

- gebruik **desktop** voor dagelijks werk op macOS, Windows of Linux
- gebruik **web** voor toegang op afstand en voor het beoordelen van werk op uw telefoon
- de **VS Code**-vermeldingen zijn van upstream OpenChamber en verspreiden Skynex niet
