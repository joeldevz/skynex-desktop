# 快速开始

## 最快路径

CLI 步骤要求 Skynex 发布版本包含 CLI 附件。已发布的 0.1.1 没有 CLI 附件或新链接协议。这些改动尚未发布。请先查看[安装](/zh-cn/install/)。

1. 安装 [OpenCode](https://opencode.ai)。
2. 按[安装](/zh-cn/install/)说明安装 Skynex 应用 CLI。
3. 运行 `skynex-app --ui-password be-creative-here`。
4. 打开 CLI 输出的 URL（通常是 `http://localhost:3000`）。
5. 想在手机上使用，启动一个[隧道](/zh-cn/tunnels/)并扫描二维码。

浏览器应显示 Skynex 会话列表。单独的 `skynex` 命令管理智能体工具。

请使用强 UI 密码，尤其是当你打算将实例开放到互联网时。

如果页面无法加载，请查看[问题排查](/zh-cn/troubleshooting/)。

## 我应该使用哪个应用？

- 在 macOS、Windows 或 Linux 上的日常工作中使用 **桌面**
- 在远程访问和移动端审查时使用 **Web**
- **VS Code** 上的发布属于上游 OpenChamber，不分发 Skynex
