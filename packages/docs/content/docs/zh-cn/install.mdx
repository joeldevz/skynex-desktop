# 安装

选择适合你工作方式的应用：

- 面向 macOS、Windows 和 Linux 的桌面应用
- 由 CLI 运行的 Web 应用，可以像手机应用一样安装（即 PWA）

## 桌面

从 [Skynex GitHub Releases](https://github.com/joeldevz/skynex-desktop/releases/latest) 下载可用构建。支持的平台和格式以该版本的附件为准。

桌面应用包含编程智能体 [OpenCode](https://opencode.ai)。

## Web + PWA

Web 应用需要在运行它的机器上安装 [OpenCode](https://opencode.ai) 和 Node.js 24.14 或更高版本。

安装程序要求发布版本包含 CLI 附件。已发布的 0.1.1 没有 CLI 附件，也不支持 `skynex-app://` 链接。当前工作副本的改动尚未发布。请在包含 CLI 附件的版本发布后运行：

```bash
curl -fsSL https://github.com/joeldevz/skynex-desktop/releases/latest/download/install.sh | bash
skynex-app --ui-password be-creative-here
```

安装需主动选择，使用用户专属的管理目录和固定启动器。安装程序和原生包来自同一发布版本。包内包含应用依赖和 SDK。`skynex-app` 用于应用，`skynex` 用于智能体工具。SSH 和服务仍可使用 `openchamber` 可执行文件别名。

打开输出的 URL，通常为 `http://localhost:3000`。页面应显示 Skynex 会话列表。可通过浏览器的安装选项添加 PWA。

`skynex-app update` 在激活前验证 SHA256，并保留旧版本。运行中的服务器保持运行，需明确执行 `skynex-app restart` 才会重启。源码安装和非托管安装会拒绝更新，不修改文件或运行中的服务器。没有 npm 回退。Web 界面可能要求手动运行 CLI 命令。

新链接仅使用 `skynex-app://`，不接受旧的 `openchamber://` 链接。配置、存储路径和环境变量保留现有技术名称。

## VS Code

[VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=fedaykindev.openchamber) 和 [Open VSX](https://open-vsx.org/extension/FedaykinDev/openchamber) 上的 OpenChamber 属于上游项目，不分发 Skynex。

## 移动应用

[移动指南](/zh-cn/mobile/) 描述上游应用。此处尚未确认 Skynex 移动应用的发布。手机上可使用 Web 应用或 PWA。
