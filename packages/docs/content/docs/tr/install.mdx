# Kurulum

Çalışma biçiminize uyan uygulamayı seçin:

- macOS, Windows ve Linux için masaüstü uygulaması
- CLI tarafından çalıştırılan web uygulaması, bunu telefon uygulaması gibi yükleyebilirsiniz, yani PWA

## Masaüstü

[Skynex GitHub Releases](https://github.com/joeldevz/skynex-desktop/releases/latest) üzerinden mevcut bir derlemeyi indirin. Desteklenen platformlar ve biçimler için sürüm dosyalarına bakın.

Masaüstü uygulaması [OpenCode](https://opencode.ai) kodlama ajanını içerir.

## Web + PWA

Web uygulaması, çalıştığı makinede [OpenCode](https://opencode.ai) ve Node.js 24.14 ya da daha yenisini gerektirir.

Kurucu, CLI dosyalarını içeren bir sürüm gerektirir. Yayımlanan 0.1.1 sürümünde CLI dosyaları veya `skynex-app://` bağlantıları yoktur. Bu çalışma kopyasındaki değişiklikler yayımlanmamıştır. Komutu yalnızca CLI dosyalarını içeren bir sürüm yayımlandıktan sonra çalıştırın:

```bash
curl -fsSL https://github.com/joeldevz/skynex-desktop/releases/latest/download/install.sh | bash
skynex-app --ui-password be-creative-here
```

Kurulum isteğe bağlıdır ve kullanıcıya özel yönetilen bir alan ile sabit başlatıcı kullanır. Kurucu ve yerel paketler aynı sürümden gelir. Paketler uygulama bağımlılıklarını ve SDK'yı içerir. Uygulama komutu `skynex-app`, ajan araçları komutu `skynex` olarak kalır. SSH ve hizmetler için `openchamber` takma adı korunur.

Yazdırılan URL'yi açın, genellikle `http://localhost:3000`. Skynex oturum listesini görmelisiniz. Tarayıcının yükleme seçeneğiyle PWA olarak ekleyebilirsiniz.

`skynex-app update`, etkinleştirmeden önce SHA256 doğrular ve önceki sürümü korur. Sunucular açık kalır. Hazır olduğunuzda `skynex-app restart` komutunu açıkça çalıştırın. Kaynak ve yönetilmeyen kurulumlar dosya veya sunucu değiştirmeden güncellemeyi reddeder. npm yedeği yoktur. Web arayüzü elle CLI komutu çalıştırmanızı isteyebilir.

Yeni bağlantılar yalnızca `skynex-app://` kullanır. Eski `openchamber://` bağlantıları kabul edilmez. Profiller, depolama yolları ve ortam değişkenleri teknik adlarını korur.

## VS Code

[VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=fedaykindev.openchamber) ve [Open VSX](https://open-vsx.org/extension/FedaykinDev/openchamber) üzerindeki OpenChamber yayınları upstream projesine aittir. Skynex dağıtmazlar.

## Mobil

[Mobil kılavuz](/tr/mobile/) upstream uygulamalarını açıklar. Skynex mobil yayını burada doğrulanmamıştır. Telefonda web uygulamasını veya PWA'yı kullanın.
