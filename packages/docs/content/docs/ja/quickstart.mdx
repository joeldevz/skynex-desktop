# クイックスタート

## 最短手順

CLI の手順には CLI ファイルを含む Skynex リリースが必要です。公開済みの 0.1.1 には CLI ファイルも新しいリンク形式もありません。この変更は未公開です。先に [インストール](/ja/install/) を確認してください。

1. [OpenCode](https://opencode.ai) をインストールします。
2. [インストール](/ja/install/) に従って Skynex アプリの CLI をインストールします。
3. `skynex-app --ui-password be-creative-here` を実行します。
4. CLI が表示する URL（通常は `http://localhost:3000`）を開きます。
5. スマートフォンから使うには、[トンネル](/tunnels/) を開始して QR コードをスキャンします。

ブラウザに Skynex のセッション一覧が表示されます。別のコマンド `skynex` はエージェントツールを管理します。

特にインスタンスをインターネットに公開する予定がある場合は、強力な UI パスワードを使ってください。

ページが読み込まれない場合は、[トラブルシューティング](/troubleshooting/) を確認してください。

## どのアプリを使うべきですか？

- macOS、Windows、Linux での日常作業には **desktop** を使います
- リモートアクセスやスマートフォンからの確認には **web** を使います
- **VS Code** の公開物は上流の OpenChamber に属し、Skynex の配布ではありません
