# Quickstart

## Fastest path

The CLI steps require a Skynex release containing CLI assets. Published 0.1.1 has no CLI assets or new connection scheme. These checkout changes are not published. Check [Install](/install/) before continuing.

1. Install [OpenCode](https://opencode.ai).
2. Install the Skynex application CLI using [Install](/install/).
3. Run `skynex-app --ui-password be-creative-here`.
4. Open the URL the CLI prints (usually `http://localhost:3000`).
5. To use it from your phone, start a [tunnel](/tunnels/) and scan the QR code.

You should see the Skynex session list in your browser. The separate `skynex` command manages agent tooling.

Use a strong UI password, especially if you plan to open the instance to the internet.

If the page doesn't load, check [Troubleshooting](/troubleshooting/).

## Which app should I use?

- use **desktop** for day-to-day work on macOS, Windows, or Linux
- use **web** for remote access and reviewing from your phone
- the **VS Code** listings belong to upstream OpenChamber; they do not distribute Skynex
