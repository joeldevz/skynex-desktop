# Instalación

Elige la app que encaje con tu forma de trabajar:

- app de escritorio para macOS, Windows y Linux
- app web que ejecuta la CLI, que puedes instalar como una app de teléfono (una PWA)

## Escritorio

Descarga una compilación disponible desde [Skynex GitHub Releases](https://github.com/joeldevz/skynex-desktop/releases/latest). Revisa los archivos de la versión para conocer las plataformas y formatos disponibles.

La app de escritorio incluye el agente de código [OpenCode](https://opencode.ai).

## Web + PWA

La app web necesita [OpenCode](https://opencode.ai) y Node.js 24.14 o posterior en la máquina donde se ejecuta.

El instalador requiere una versión con archivos CLI. La versión publicada 0.1.1 no incluye archivos CLI ni enlaces `skynex-app://`. Los cambios de este checkout no están publicados. Ejecuta el comando solo cuando una versión incluya los archivos CLI:

```bash
curl -fsSL https://github.com/joeldevz/skynex-desktop/releases/latest/download/install.sh | bash
skynex-app --ui-password be-creative-here
```

La instalación es opcional y por usuario, con un lanzador estable. El instalador y los paquetes nativos proceden de la misma versión. Los paquetes incluyen las dependencias de la app y el SDK. `skynex-app` ejecuta la app; `skynex` gestiona herramientas de agentes. El alias `openchamber` se conserva para SSH y servicios.

Abre la URL que muestra la CLI, normalmente `http://localhost:3000`. Verás la lista de sesiones de Skynex. Usa la opción de instalación del navegador para añadir la PWA.

`skynex-app update` verifica SHA256 antes de activar la versión y conserva la anterior. Los servidores siguen ejecutándose hasta un `skynex-app restart` explícito. Las instalaciones desde código fuente o no gestionadas rechazan la actualización sin modificar archivos ni servidores. No hay alternativa mediante npm. La web puede requerir el comando CLI manual.

Los enlaces nuevos usan solo `skynex-app://`. Los antiguos `openchamber://` no se aceptan. Los perfiles, rutas de almacenamiento y variables de entorno conservan sus nombres técnicos.

## VS Code

Las publicaciones de OpenChamber en [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=fedaykindev.openchamber) y [Open VSX](https://open-vsx.org/extension/FedaykinDev/openchamber) pertenecen al proyecto original. No distribuyen Skynex.

## Móvil

La [guía móvil](/es/mobile/) describe las apps del proyecto original. Aquí no se confirma una publicación móvil de Skynex. Usa la app web o PWA en el teléfono.
