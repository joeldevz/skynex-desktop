# Inicio rápido

## La vía más rápida

Los pasos CLI requieren una versión de Skynex con archivos CLI. La versión publicada 0.1.1 no incluye archivos CLI ni el nuevo esquema de enlaces. Estos cambios no están publicados. Consulta [Instalación](/es/install/) antes de continuar.

1. Instala [OpenCode](https://opencode.ai).
2. Instala la CLI de la app Skynex según [Instalación](/es/install/).
3. Ejecuta `skynex-app --ui-password be-creative-here`.
4. Abre la URL que imprime la CLI (normalmente `http://localhost:3000`).
5. Para usarlo desde tu teléfono, inicia un [túnel](/es/tunnels/) y escanea el código QR.

Deberías ver la lista de sesiones de Skynex en el navegador. El comando separado `skynex` gestiona herramientas de agentes.

Usa una contraseña de UI fuerte, sobre todo si piensas exponer la instancia a internet.

Si la página no carga, consulta [Resolución de problemas](/es/troubleshooting/).

## ¿Qué app debería usar?

- usa **escritorio** para el día a día en macOS, Windows o Linux
- usa **web** para acceso remoto y revisión desde el teléfono
- las publicaciones de **VS Code** pertenecen a OpenChamber upstream; no distribuyen Skynex
