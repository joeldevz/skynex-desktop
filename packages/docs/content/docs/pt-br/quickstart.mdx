# Início rápido

## Caminho mais rápido

Os passos CLI exigem uma versão do Skynex com arquivos CLI. A versão publicada 0.1.1 não contém arquivos CLI nem o novo esquema de links. Estas mudanças não foram publicadas. Confira [Instalação](/pt-br/install/) antes de continuar.

1. Instale o [OpenCode](https://opencode.ai).
2. Instale a CLI do app Skynex conforme [Instalação](/pt-br/install/).
3. Execute `skynex-app --ui-password be-creative-here`.
4. Abra a URL que a CLI imprime (geralmente `http://localhost:3000`).
5. Para usar pelo celular, inicie um [túnel](/pt-br/tunnels/) e escaneie o QR code.

Você deve ver a lista de sessões do Skynex no navegador. O comando separado `skynex` gerencia ferramentas de agentes.

Use uma senha de UI forte, principalmente se pretende expor a instância à internet.

Se a página não carregar, confira a [Solução de problemas](/pt-br/troubleshooting/).

## Qual plataforma devo usar?

- use **desktop** para o uso diário no macOS, Windows ou Linux
- use **web** para acesso remoto e revisão pelo celular
- as publicações **VS Code** pertencem ao OpenChamber upstream e não distribuem o Skynex
