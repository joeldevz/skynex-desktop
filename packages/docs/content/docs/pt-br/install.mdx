# Instalação

Escolha o app que combina com o seu jeito de trabalhar:

- app de desktop para macOS, Windows e Linux
- app web executado pela CLI, que você pode instalar como um app de celular (um PWA)

## Desktop

Baixe uma compilação disponível no [Skynex GitHub Releases](https://github.com/joeldevz/skynex-desktop/releases/latest). Confira os arquivos da versão para saber as plataformas e os formatos disponíveis.

O app de desktop inclui o agente de código [OpenCode](https://opencode.ai).

## Web + PWA

O app web precisa do [OpenCode](https://opencode.ai) e do Node.js 24.14 ou mais recente na máquina onde ele roda.

O instalador exige uma versão com arquivos CLI. A versão publicada 0.1.1 não contém arquivos CLI nem links `skynex-app://`. As mudanças deste checkout não foram publicadas. Execute somente depois que uma versão incluir os arquivos CLI:

```bash
curl -fsSL https://github.com/joeldevz/skynex-desktop/releases/latest/download/install.sh | bash
skynex-app --ui-password be-creative-here
```

A instalação é opcional e por usuário, com um inicializador estável. O instalador e os pacotes nativos vêm da mesma versão. Os pacotes incluem dependências do app e SDK. `skynex-app` executa o app; `skynex` gerencia ferramentas de agentes. O alias `openchamber` permanece para SSH e serviços.

Abra a URL exibida, normalmente `http://localhost:3000`. A lista de sessões do Skynex deve aparecer. Use a opção de instalação do navegador para adicionar o PWA.

`skynex-app update` verifica SHA256 antes da ativação e preserva a versão anterior. Os servidores continuam rodando até um `skynex-app restart` explícito. Instalações pelo código-fonte ou não gerenciadas recusam atualizações sem modificar arquivos ou servidores. Não há alternativa via npm. A web pode exigir o comando CLI manual.

Novos links usam apenas `skynex-app://`. Links antigos `openchamber://` não são aceitos. Perfis, caminhos de armazenamento e variáveis de ambiente mantêm seus nomes técnicos.

## VS Code

As publicações do OpenChamber no [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=fedaykindev.openchamber) e no [Open VSX](https://open-vsx.org/extension/FedaykinDev/openchamber) pertencem ao projeto upstream. Elas não distribuem o Skynex.

## Celular

O [guia móvel](/pt-br/mobile/) descreve apps upstream. Uma publicação móvel do Skynex não está confirmada aqui. Use o app web ou PWA no celular.
