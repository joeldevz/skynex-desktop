# 빠른 시작

## 가장 빠른 경로

CLI 단계에는 CLI 파일이 포함된 Skynex 릴리스가 필요합니다. 공개된 0.1.1에는 CLI 파일이나 새 링크 형식이 없습니다. 이 변경 사항은 아직 공개되지 않았습니다. 먼저 [설치](/ko/install/)를 확인하세요.

1. [OpenCode](https://opencode.ai)를 설치합니다.
2. [설치](/ko/install/)에 따라 Skynex 앱 CLI를 설치합니다.
3. `skynex-app --ui-password be-creative-here`를 실행합니다.
4. CLI가 출력한 URL을 엽니다(보통 `http://localhost:3000`).
5. 휴대폰에서 사용하려면 [터널](/ko/tunnels/)을 시작하고 QR 코드를 스캔합니다.

브라우저에 Skynex 세션 목록이 나타납니다. 별도 명령 `skynex`는 에이전트 도구를 관리합니다.

특히 인스턴스를 인터넷에 공개할 계획이라면 강력한 UI 비밀번호를 사용하세요.

페이지가 열리지 않으면 [문제 해결](/ko/troubleshooting/)을 확인하세요.

## 어떤 앱을 사용해야 하나요?

- macOS, Windows, Linux에서의 일상 작업에는 **데스크톱**을 사용하세요
- 원격 접근과 휴대폰 검토에는 **웹**을 사용하세요
- **VS Code** 배포는 업스트림 OpenChamber의 배포이며 Skynex를 제공하지 않습니다
