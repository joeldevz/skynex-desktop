# 설치

작업 방식에 맞는 앱을 고르세요.

- macOS, Windows, Linux용 데스크톱 앱
- CLI가 실행하는 웹 앱으로, 휴대폰 앱처럼 설치할 수 있습니다(PWA)

## 데스크톱

[Skynex GitHub Releases](https://github.com/joeldevz/skynex-desktop/releases/latest)에서 제공되는 빌드를 받으세요. 지원 플랫폼과 형식은 각 릴리스 파일에서 확인하세요.

데스크톱 앱에는 코딩 에이전트 [OpenCode](https://opencode.ai)가 포함되어 있습니다.

## 웹 + PWA

웹 앱을 실행하는 머신에는 [OpenCode](https://opencode.ai)와 Node.js 24.14 이상이 필요합니다.

설치 프로그램에는 CLI 파일이 포함된 릴리스가 필요합니다. 공개된 0.1.1에는 CLI 파일이나 `skynex-app://` 링크가 없습니다. 이 체크아웃의 변경 사항은 아직 공개되지 않았습니다. CLI 파일이 포함된 릴리스가 나온 후 실행하세요.

```bash
curl -fsSL https://github.com/joeldevz/skynex-desktop/releases/latest/download/install.sh | bash
skynex-app --ui-password be-creative-here
```

설치는 선택 사항이며 사용자별 관리 경로와 고정 실행기를 사용합니다. 설치 프로그램과 네이티브 번들은 같은 릴리스에서 받습니다. 번들에는 앱 의존성과 SDK가 포함됩니다. 앱 명령은 `skynex-app`이고 에이전트 도구 명령은 `skynex`입니다. SSH와 서비스용 `openchamber` 별칭은 유지됩니다.

출력된 URL, 보통 `http://localhost:3000`을 열면 Skynex 세션 목록이 나타납니다. 브라우저 설치 옵션으로 PWA를 추가할 수 있습니다.

`skynex-app update`는 활성화 전에 SHA256을 검증하고 이전 버전을 보존합니다. 실행 중인 서버는 그대로 유지됩니다. 준비되면 `skynex-app restart`를 직접 실행하세요. 소스 및 비관리 설치는 파일이나 서버를 변경하지 않고 업데이트를 거부합니다. npm 대체 설치는 없습니다. 웹에서는 CLI 명령을 직접 실행해야 할 수 있습니다.

새 링크는 `skynex-app://`만 사용합니다. 이전 `openchamber://` 링크는 허용되지 않습니다. 프로필, 저장 경로, 환경 변수의 기술 이름은 유지됩니다.

## VS Code

[VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=fedaykindev.openchamber)와 [Open VSX](https://open-vsx.org/extension/FedaykinDev/openchamber)의 OpenChamber는 업스트림 프로젝트의 배포입니다. Skynex 배포가 아닙니다.

## 모바일

[모바일 안내](/ko/mobile/)는 업스트림 앱을 설명합니다. Skynex 모바일 배포는 여기서 확인되지 않았습니다. 휴대폰에서는 웹 앱이나 PWA를 사용하세요.
