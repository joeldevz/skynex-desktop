# Démarrage rapide

## Chemin le plus rapide

Ces étapes exigent une version Skynex contenant les fichiers CLI. La version publiée 0.1.1 ne contient ni fichiers CLI ni nouveau schéma de liens. Ces changements ne sont pas publiés. Consultez [Installation](/fr/install/) avant de continuer.

1. Installez [OpenCode](https://opencode.ai).
2. Installez la CLI de l'application Skynex selon [Installation](/fr/install/).
3. Lancez `skynex-app --ui-password be-creative-here`.
4. Ouvrez l’URL affichée par la CLI (souvent `http://localhost:3000`).
5. Pour l’utiliser depuis votre téléphone, démarrez un [tunnel](/tunnels/) et scannez le QR code.

La liste des sessions Skynex apparaît dans le navigateur. La commande distincte `skynex` gère les outils d'agents.

Utilisez un mot de passe UI robuste, surtout si vous prévoyez d’ouvrir l’instance à internet.

Si la page ne se charge pas, consultez le [dépannage](/troubleshooting/).

## Quelle application utiliser ?

- utilisez **desktop** pour le travail quotidien sur macOS, Windows ou Linux
- utilisez **web** pour l’accès distant et la revue depuis votre téléphone
- les publications **VS Code** appartiennent au projet amont OpenChamber et ne distribuent pas Skynex
