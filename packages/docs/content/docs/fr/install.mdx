# Installation

Choisissez l’application qui correspond à votre façon de travailler :

- l’application desktop pour macOS, Windows et Linux
- l’application web lancée par la CLI, que vous pouvez installer comme une application de téléphone (une PWA)

## Desktop

Téléchargez une version disponible depuis [Skynex GitHub Releases](https://github.com/joeldevz/skynex-desktop/releases/latest). Consultez ses fichiers pour connaître les plateformes et formats disponibles.

L'application desktop inclut l'agent de code [OpenCode](https://opencode.ai).

## Web + PWA

L’application web a besoin d’[OpenCode](https://opencode.ai) et de Node.js 24.14 ou plus récent sur la machine qui l’exécute.

L'installateur exige une version contenant les fichiers CLI. La version publiée 0.1.1 ne contient ni fichiers CLI ni liens `skynex-app://`. Les changements de ce checkout ne sont pas publiés. Exécutez cette commande seulement lorsqu'une version contient les fichiers CLI :

```bash
curl -fsSL https://github.com/joeldevz/skynex-desktop/releases/latest/download/install.sh | bash
skynex-app --ui-password be-creative-here
```

L'installation est facultative et propre à chaque utilisateur, avec un lanceur stable. L'installateur et les archives natives proviennent de la même version. Les archives incluent les dépendances et le SDK. `skynex-app` lance l'application ; `skynex` gère les outils d'agents. L'alias `openchamber` reste disponible pour SSH et les services.

Ouvrez l'URL affichée, généralement `http://localhost:3000`. La liste des sessions Skynex apparaît. Utilisez l'option d'installation du navigateur pour ajouter la PWA.

`skynex-app update` vérifie SHA256 avant l'activation et conserve la version précédente. Les serveurs restent actifs jusqu'à un `skynex-app restart` explicite. Les installations depuis les sources ou non gérées refusent la mise à jour sans modifier les fichiers ni les serveurs. Aucun recours à npm n'est prévu. Le web peut demander une commande CLI manuelle.

Les nouveaux liens utilisent uniquement `skynex-app://`. Les anciens liens `openchamber://` sont refusés. Les profils, chemins de stockage et variables d'environnement gardent leurs noms techniques.

## VS Code

Les publications OpenChamber sur [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=fedaykindev.openchamber) et [Open VSX](https://open-vsx.org/extension/FedaykinDev/openchamber) appartiennent au projet amont. Elles ne distribuent pas Skynex.

## Mobile

Le [guide mobile](/fr/mobile/) décrit les applications amont. Aucune publication mobile Skynex n'est confirmée ici. Utilisez l'application web ou la PWA sur téléphone.
