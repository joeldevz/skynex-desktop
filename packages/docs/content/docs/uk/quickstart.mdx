# Швидкий старт

## Найшвидший шлях

Кроки CLI потребують релізу Skynex із файлами CLI. Опублікована версія 0.1.1 не містить файлів CLI чи нової схеми посилань. Ці зміни не опубліковані. Спершу перегляньте [Встановлення](/uk/install/).

1. Встановіть [OpenCode](https://opencode.ai).
2. Встановіть CLI застосунку Skynex за [інструкцією](/uk/install/).
3. Виконайте `skynex-app --ui-password be-creative-here`.
4. Відкрийте URL, який вивів CLI (зазвичай `http://localhost:3000`).
5. Щоб користуватися з телефона, запустіть [тунель](/uk/tunnels/) і відскануйте QR-код.

У браузері з'явиться список сесій Skynex. Окрема команда `skynex` керує інструментами агентів.

Використовуйте надійний пароль UI, особливо якщо плануєте відкривати доступ до інстансу з інтернету.

Якщо сторінка не завантажується, перегляньте [Усунення несправностей](/uk/troubleshooting/).

## Яку платформу обрати?

- обирайте **десктоп** для щоденної роботи на macOS, Windows або Linux
- обирайте **веб** для віддаленого доступу та перегляду з телефона
- публікації **VS Code** належать upstream-проєкту OpenChamber і не поширюють Skynex
