# Встановлення

Оберіть застосунок під свій спосіб роботи:

- десктоп-застосунок для macOS, Windows і Linux
- вебзастосунок на базі CLI, який можна встановити як застосунок на телефоні (PWA)

## Десктоп

Завантажте доступну збірку зі [Skynex GitHub Releases](https://github.com/joeldevz/skynex-desktop/releases/latest). Підтримувані платформи й формати вказані у файлах релізу.

Десктоп-застосунок містить агента для програмування [OpenCode](https://opencode.ai).

## Веб + PWA

Для вебзастосунку на машині, де він працює, потрібні [OpenCode](https://opencode.ai) і Node.js 24.14 або новіший.

Інсталятору потрібен реліз із файлами CLI. Опублікована версія 0.1.1 не містить файлів CLI чи посилань `skynex-app://`. Зміни в цій робочій копії не опубліковані. Виконуйте команду лише після виходу релізу з файлами CLI:

```bash
curl -fsSL https://github.com/joeldevz/skynex-desktop/releases/latest/download/install.sh | bash
skynex-app --ui-password be-creative-here
```

Встановлення добровільне, окреме для користувача, зі сталим засобом запуску. Інсталятор і нативні пакети походять з одного релізу. Пакети містять залежності застосунку та SDK. `skynex-app` запускає застосунок, а `skynex` керує інструментами агентів. Псевдонім `openchamber` зберігається для SSH і служб.

Відкрийте виведений URL, зазвичай `http://localhost:3000`. З'явиться список сесій Skynex. Додайте PWA через опцію встановлення в браузері.

`skynex-app update` перевіряє SHA256 до активації та зберігає попередню версію. Сервери продовжують працювати до явного `skynex-app restart`. Встановлення з джерел і некеровані встановлення відмовляють в оновленні без змін файлів або серверів. Резервного встановлення через npm немає. Вебінтерфейс може вимагати ручної команди CLI.

Нові посилання використовують лише `skynex-app://`. Старі `openchamber://` не приймаються. Профілі, шляхи зберігання та змінні середовища зберігають технічні назви.

## VS Code

Публікації OpenChamber у [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=fedaykindev.openchamber) та [Open VSX](https://open-vsx.org/extension/FedaykinDev/openchamber) належать upstream-проєкту. Вони не поширюють Skynex.

## Мобільні застосунки

[Мобільний посібник](/uk/mobile/) описує upstream-застосунки. Мобільний реліз Skynex тут не підтверджено. На телефоні користуйтеся вебзастосунком або PWA.
