# Instalacja

Wybierz aplikację, która pasuje do twojego sposobu pracy:

- aplikacja na komputer dla macOS, Windows i Linuksa
- aplikacja webowa uruchamiana przez CLI, którą możesz zainstalować jak aplikację na telefonie (jako PWA)

## Komputer

Pobierz dostępną kompilację z [Skynex GitHub Releases](https://github.com/joeldevz/skynex-desktop/releases/latest). Sprawdź pliki wydania, aby poznać dostępne platformy i formaty.

Aplikacja na komputer zawiera agenta programistycznego [OpenCode](https://opencode.ai).

## Przeglądarka + PWA

Aplikacja webowa potrzebuje [OpenCode](https://opencode.ai) i Node.js w wersji 24.14 lub nowszej na maszynie, na której działa.

Instalator wymaga wydania z plikami CLI. Opublikowana wersja 0.1.1 nie zawiera plików CLI ani linków `skynex-app://`. Zmiany w tej kopii roboczej nie są opublikowane. Uruchom polecenie dopiero po wydaniu plików CLI:

```bash
curl -fsSL https://github.com/joeldevz/skynex-desktop/releases/latest/download/install.sh | bash
skynex-app --ui-password be-creative-here
```

Instalacja jest opcjonalna i przypisana do użytkownika, ze stałym programem uruchamiającym. Instalator i natywne archiwa pochodzą z tego samego wydania. Archiwa zawierają zależności aplikacji i SDK. `skynex-app` uruchamia aplikację, a `skynex` zarządza narzędziami agentów. Alias `openchamber` pozostaje dla SSH i usług.

Otwórz podany URL, zwykle `http://localhost:3000`. Zobaczysz listę sesji Skynex. Opcja instalacji w przeglądarce pozwala dodać PWA.

`skynex-app update` sprawdza SHA256 przed aktywacją i zachowuje poprzednią wersję. Serwery działają do jawnego `skynex-app restart`. Instalacje ze źródeł i niezarządzane odmawiają aktualizacji bez zmiany plików lub serwerów. Nie ma instalacji zastępczej przez npm. Wersja webowa może wymagać ręcznego polecenia CLI.

Nowe linki używają tylko `skynex-app://`. Stare linki `openchamber://` są odrzucane. Profile, ścieżki danych i zmienne środowiskowe zachowują nazwy techniczne.

## VS Code

Publikacje OpenChamber w [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=fedaykindev.openchamber) i [Open VSX](https://open-vsx.org/extension/FedaykinDev/openchamber) należą do projektu upstream. Nie udostępniają Skynex.

## Telefon

[Przewodnik mobilny](/pl/mobile/) opisuje aplikacje upstream. Publikacja mobilna Skynex nie jest tu potwierdzona. Na telefonie użyj aplikacji webowej lub PWA.
