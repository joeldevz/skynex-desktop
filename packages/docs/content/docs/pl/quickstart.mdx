# Szybki start

## Najszybsza droga

Te kroki wymagają wydania Skynex z plikami CLI. Opublikowana wersja 0.1.1 nie ma plików CLI ani nowego schematu linków. Te zmiany nie są opublikowane. Najpierw sprawdź [Instalację](/pl/install/).

1. Zainstaluj [OpenCode](https://opencode.ai).
2. Zainstaluj CLI aplikacji Skynex według [Instalacji](/pl/install/).
3. Uruchom `skynex-app --ui-password be-creative-here`.
4. Otwórz adres URL wypisany przez CLI (zwykle `http://localhost:3000`).
5. Aby korzystać z telefonu, uruchom [tunel](/pl/tunnels/) i zeskanuj kod QR.

W przeglądarce pojawi się lista sesji Skynex. Osobne polecenie `skynex` zarządza narzędziami agentów.

Używaj silnego hasła UI, zwłaszcza jeśli planujesz udostępnić instancję w internecie.

Jeśli strona się nie ładuje, zajrzyj do [Rozwiązywania problemów](/pl/troubleshooting/).

## Której platformy użyć?

- użyj **komputera** do codziennej pracy na macOS, Windows lub Linuksie
- użyj **przeglądarki** do zdalnego dostępu i przeglądania na telefonie
- publikacje **VS Code** należą do projektu upstream OpenChamber i nie udostępniają Skynex
